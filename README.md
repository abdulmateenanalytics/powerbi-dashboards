# 📄 PDF Data Automation & Power BI Query Stabilization (Freelance Project)

## 📌 Overview
This is a real-world freelance Power BI project where I resolved recurring query failures caused by changing PDF report structures.

## ❗ Business Problem
The client downloaded weekly PDF reports from a website and stored them in OneDrive folders for automated Power BI reporting.

Over time, the PDF layouts changed, causing Power Query transformation steps to fail and making the reporting process unstable.

The client also struggled to identify the exact root cause of these failures.

## 🔍 Root Cause Analysis
I investigated the entire Power Query workflow step by step and identified where the transformation logic was breaking.

The main issue was that Power BI was processing PDF files with different structures using the same transformation logic.

## ✅ Solution
Instead of forcing all formats into one query, I redesigned the solution by:

- Creating separate Power Query transformations for each PDF structure
- Cleaning and standardizing outputs independently
- Appending all cleaned datasets into one final consolidated table

## 🚀 Impact
- Fixed recurring query break issues
- Improved reporting stability
- Reduced manual troubleshooting
- Created a scalable and maintainable solution
- Identified the exact root cause of failures

## 🛠 Technical Highlights
- Power Query transformation & cleanup
- PDF data extraction using Power BI
- Root cause analysis
- Folder-based automation
- Append queries & data consolidation
